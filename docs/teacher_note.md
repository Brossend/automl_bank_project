# Комментарий по выбору темы

Тема проекта выбрана самостоятельно в рамках цели задания: автоматизировать ML-пайплайн на любом датасете.

Выбранная тема:

> Автоматизация ML-пайплайна для прогнозирования отклика клиента на банковскую маркетинговую кампанию.

Датасет:

> UCI Machine Learning Repository - Bank Marketing Dataset.

Источник:

https://archive.ics.uci.edu/dataset/222/bank+marketing

Почему тема подходит под задание:

- используется реальный открытый датасет;
- задача относится к бизнес-домену;
- задача является задачей классификации;
- есть понятный целевой признак `y`;
- можно реализовать ETL;
- можно автоматизировать обучение через Optuna;
- можно добавить тестирование, Docker, CI/CD, MLflow и мониторинг.
